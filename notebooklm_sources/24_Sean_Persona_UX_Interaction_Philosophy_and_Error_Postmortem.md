## 🏛️ 1. 박시현(Sean Park) 대표의 독보적 페르소나 & 사고방식

1. **"대도서관 디지털화 (Digital Grand Library) 메타포"**:
   - 정보가 조잡하게 널려 있는 것을 극도로 기피함.
   - 웅장한 대도서관 서가처럼 **"오직 지금 내게 필요한 핵심 항목만 눈앞에 스포트라이트로 활성화되고, 처리가 끝난 항목은 서가에 책을 꽂아두듯 자연스럽게 제자리로 돌아가 보존되는 구조"**를 선호함.

2. **"화면 들어왔을 때 '어쩌라고' 느낌 절대 금지 (Zero Friction Onboarding)"**:
   - Finom, Amie처럼 화면을 열자마자 사용자가 무엇을 해야 하는지 1초 만에 인지하고, 한 화면에서 친절하게 계속 안내받으며 미션을 클리어하는 몰입감을 요구함.
   - 진입 즉시 **오늘({today}일) 기준 가장 시급한 퀘스트 빔(`Today Quest Beam`)**이 켜지고, **스페이스바(`Space`) 하나로 검토/완료가 일사천리로 이어지는 원키 게임 루프**를 지향.

3. **"어설픈 2D 위아래 분할 강박 타파 (Unified Spatial Horizon)"**:
   - 상단에 슬라이더나 메뉴 바를 억지로 붙이고 하단에 달력 테이블을 낑겨 넣는 '2단 분할'은 시각적 답답함의 주원인.
   - 화면 전체가 하나의 단일한 3D 공간(Room Canvas)이어야 하며, 달력 타일 위에 3D 카드가 실제로 서 있는 일체형 구조를 원함.

4. **"3D는 과시가 아닌 '정보의 위계와 뎁스(Depth)'를 위한 절제된 도구"**:
   - 삐딱하게 누워 왜곡되는 3D(Perspective Distortion)가 아니라, **정면 8~10°의 극도로 안정감 있고 고급스러운 럭셔리 2.5D Isometric 뎁스**여야 함.
   - 어떤 화면 비율에서도 **브라우저 스크롤 0%로 1일~31일이 한눈에 들어오는 완벽한 뷰포트 핏(No-Scroll Fit)**이 기본 전제.

5. **"스크롤 구동 3D 공간 레이어 전환 (Layer-Shift Architecture)"**:
   - **1레이어 (기본)**: 상단 메뉴조차 100% 숨기고 오직 순수한 3D 달력 그 자체만 정면 배치.
   - **2레이어 (컨트롤 덱)**: 마우스 휠을 아래로 굴리거나 `Tab` 키/제스처 시 1레이어가 3D 뒤로 가라앉으며(`translateZ(-220px)`) 3단 우선순위 필터와 재무 정산 덱이 눈앞으로 떠오름.

## ⚠️ 3. AI 어시스턴트가 가장 많이 헤맸던 실수 & 해결 포스트모템

### ❌ 실수 1: 카드가 뒤집힐 때 뒷면이 안 보이고 멍하니 거울상만 비침
- **원인**: CSS 3D 트랜스폼 시 앞면과 뒷면에 `backfaceVisibility: 'hidden'` 및 `-webkit-backface-visibility: 'hidden'`을 엄격히 지정하지 않아, 180도 회전 시 앞면의 거울상이 뒷면을 가림.
- **해결책**: 독립된 듀얼 페이스(Front `rotateY(0deg)`, Back `rotateY(180deg)`) 래퍼에 `transformStyle: 'preserve-3d'`와 `WebkitBackfaceVisibility: 'hidden'`을 완벽히 주입하여 선명한 인스펙터 렌더링 성공.

### ❌ 실수 2: 카드를 열었을 때 배경을 85% 검정으로 덮어버림
- **원인**: 모달의 일반적인 암전(Dimming) 관성에 빠져, 뒤쪽 달력 룸 전체를 가려버림.
- **대표님 피드백**: *"화면 전체를 덮지 말고 뒤쪽 달력도 살짝 보이게 해줘. 내용 파악해야 하니깐."*
- **해결책**: `bg-black/35 backdrop-blur-[3px]`의 투명 앰비언트 글래스 뎁스로 교체하여, 카드를 열어둔 상태에서도 뒤쪽 1~31일의 전체 일정 맥락이 훤히 조망되도록 최적화.

### ❌ 실수 3: 3D 각도를 과하게 주어 화면이 삐딱하게 누워 보임
- **원인**: `rotateX(26deg)`의 과도한 시점 때문에 3D 원근법에 의해 윗줄이 좁아지는 사다리꼴 왜곡 발생.
- **해결책**: `rotateX(8~10deg)`의 극도로 반듯하고 은은한 럭셔리 정면 2.5D 각도로 안정화.

### ❌ 실수 4: 1레이어 달력 화면에 상단 메뉴가 자꾸 남아있음
- **원인**: 상단 헤더를 항상 띄워두려는 웹 개발의 고정관념.
- **대표님 피드백**: *"달력 화면에서는 위에 메뉴들 조차도 안 보이게 해줘. 그냥 진짜 달력만 딱 보이게."*
- **해결책**: 1레이어에서는 상단 헤더를 `opacity: 0, pointerEvents: none`으로 100% 숨기고, 마우스 휠을 아래로 굴려 2레이어로 전환할 때만 부드럽게 나타나도록 완벽 분리.

## 🔮 4. 향후 AI 어시스턴트 협업 절대 수칙 (Golden Rules)

1. **대표님의 의도를 2D 박스 배치로 단순화하지 말 것**: 항상 '하나의 연결된 입체 공간'으로 설계하라.
2. **질문은 `/grill-me` 방식으로 본질적인 공간감과 인터랙션을 파고들 것**.
3. **빌드는 항상 `npm run build` 무결점 검증(25~35초)을 거치고 즉시 라이브 링크를 제공할 것**.
4. **결제/법인 팩트 데이터는 항상 실제 Gemini 검색 실측치(Notar 공증번호 495, 자본금 €1,000, 스튜디오 €483.14 등)를 100% 유지할 것**.
